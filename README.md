# Fabriquer ses outils numériques avec l'IA

Site du stand IAgora sur le vibecoding : une page, des usages, des démos qui s'ouvrent en plein écran, et quelques slides pour comprendre.

- Site statique (HTML/CSS/JS, sans build) : déployable tel quel sur Vercel.
- Ajouter ou modifier une démo : tableau `USAGES` en haut de `app.js` (vignette dans `assets/demos/`).
- Dans la modale : ◀ ▶ pour passer d'une démo à l'autre, « Quoi montrer » pour les notes animateur, Échap pour fermer.
- Lien direct vers une démo : `/#carte24h`, `/#grenier`, etc.
